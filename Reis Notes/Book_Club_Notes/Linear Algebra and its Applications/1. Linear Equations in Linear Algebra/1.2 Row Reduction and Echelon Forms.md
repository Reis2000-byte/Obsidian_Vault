- A **nonzero** row or column means a row or column that contains at least one non zero number
- **Leading entry** of a row refers to the leftmost nonzero entry
- A rectangular matrix is in **echelon form** if it ahs the following three principals:
	- All nonzero rows are above any rows of all zeros
	- Each leading entry of a row is in a column to the right of the leading entry of the row above it
	- All entries in a column below a leading entry are zeros
- If a matrix in echelon form satisfies the following additional conditions then it is in **reduced echelon form**:
	- The leading entry is in each nonzero row is 1
	- Each leading 1 is the only non zero entry in its column
- An **echelon matrix** is one that is in row echelon form

- **Uniqueness of the Reduced Echelon Form: Each matrix is row equivalent to one and only one reduced echelon matrix**
- If matrix *A* is row equivalent to **an echelon matrix** *U*, we call *U* **an echelon form** of *A*; if *U* is in reduced echelon form, we call *U* **the reduced echelon form** of *A*

## Pivot Positions

- A **pivot position** in a matrix *A* is a location in *A* that corresponds to a leading 1 in the reduced echelon form of *A*. A **pivot column** is a column of *A* that contains a pivot position
