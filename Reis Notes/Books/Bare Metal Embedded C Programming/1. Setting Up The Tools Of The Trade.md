
- ARM will license its microcontroller and processor designs to the semiconductor manufacturing firms like STM32 and Microchip who then make the physical parts with some unique feature sets of their own
- STM32 Documentation:
	- Reference Manual: Contains register information with information on every bit as well as register configurations
	- Datasheet: Provides the functional overview
	- User Manual: Focuses on development boards and describes how the board functions

- The Cortex M4 core has five main peripherals:
	- System Timer
	- Floating-Point Unit
	- System Control Block
	- Memory Protection Unit
	- Nested Vector Interrupt Controller
- When making bare metal drivers for the peripherals before referencing the cortex document is what will be the source of truth
