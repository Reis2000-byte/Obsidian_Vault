- Bare metal programming is all about working directly with the register of the micro controller which allows easier optimization for speed and efficiency
- Firmware Developments:
	- Hardware Abstraction Layers:
		- provides high level APIs for configuring every aspect of the micro
	- Low Layer:
		- leaner alternate to to HAL. STM would also provide this
	- Bare-Metal C Programming:
		- We access the registers directly using C
	- Assembly Language:
		- Instead of using C in bare-metal we just use assembly
- User LD2 is connected to D13 Arduino, PA5
- Push Buttons:
	- B1 PC13
	- B2 NRST
- Base address for the Peripherals starts at memory address 0x4000 0000 to 0x5FFF FFFF
- Can looks at memory map to go find the memory addresses of certain peripherals
- The offset address can be used to show where certain things start

- Before using certain peripherals you need to make sure that you enable the clock for it. By default the clock is disabled on unused peripherals to save power
- This technique to save power to certain parts with clock management is called **clock gating**
- Register naming convention:
	- peripheral acronym+ underscore + register acronym
	- Example: RCC_AHB1ENR:
		- RCC stands for Reset Clock Control
		- AHB1 stands for Advanced High-Performance Bus 1
		- ENR stands for Enable Register
- Setting a bit:
	- Means changing its value to 1
	-  `register |= 1 << bit_position;`
	- change the value of bit position with it being zeroed index to get to a certain bit
- Clearing a bit:
	- Means changing the value to 0
	- `register &= ~(1 << bit_position);
